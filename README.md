# Tomato Leaf Disease Detection: online demo

**Live app: https://tomato-care.streamlit.app**

A Streamlit demo of a BTech Machine Learning Lab project. It classifies photos of tomato leaves (Early Blight, Healthy,
Late Blight, Leaf Miner, Magnesium / Nitrogen / Potassium Deficiency, Spotted Wilt Virus). The project compares
classical machine learning on handcrafted features with deep learning under a **leakage-free** evaluation.

## The four models in this demo

The demo offers the two best 5-class and the two best 8-class models. "Best" follows the rule used for every choice in
the project: validation macro-F1 (ties: validation accuracy). The test set played no part in choosing them, and each
was scored on it once.

| Task | Model | Validation rank | Test accuracy (95% CI) | Test macro-F1 |
|---|---|---|---|---|
| 5-class | Ensemble (5-class): ConvNeXt-Tiny + EfficientNet-B0 (default) | 1 of 8 | **90.9%** (87.3%–94.3%, 265 photos) | 83.5% |
| 5-class | ConvNeXt-Tiny (5-class) | 2 of 8 | **89.8%** (85.8%–93.4%, 265 photos) | 81.7% |
| 8-class | ConvNeXt-Tiny (fine-tuned) + TTA (8-class) | 1 of 15 | **84.8%** (80.1%–89.3%, 290 photos) | 58.6% |
| 8-class | ConvNeXt-Tiny (fine-tuned) (8-class) | 2 of 15 | **82.1%** (76.9%–86.9%, 290 photos) | 54.1% |
<!-- models:end -->

- **The 5-class models** cover Healthy, Leaf Miner, Magnesium Deficiency, Nitrogen Deficiency and Spotted Wilt Virus.
  These five classes were chosen using validation data only. The models cannot recognise the other three conditions:
  a photo of one of them still receives one of the five labels.
- **The default model** (the 5-class ensemble) gives a diagnosis only when its calibrated confidence is at least 77%, a
  threshold fixed on validation data. On the held-out test photos it answered about 85% of them, and 96.0% of those
  answers were correct. The other models report "Uncertain" below 60% confidence.
- **The 8-class models** cover all eight conditions. The two entries are the same trained ConvNeXt-Tiny network, with
  and without test-time augmentation (TTA: the average over 8 flipped and rotated views of the photo).
- **Accuracies of different tasks are not directly comparable:** the 5-class test set (265 photos) is the part of the
  8-class test set (290 photos) that belongs to the five classes.
- The app's **Results** page reports every model the project trained, including the classical machine-learning
  baselines (Logistic Regression, SVM, Random Forest). **Grad-CAM** heat maps show where the networks looked.

## How it works

`streamlit_app.py` imports the project's own prediction code, copied unchanged from the main project:

- `backend/services/predictor.py` and `src/tomatoleaf/` handle preprocessing, test-time augmentation, temperature
  calibration, the decision threshold and Grad-CAM.
- On first use, the trained weights are downloaded from this repository's `models-v1` release.
- Each weight file is checked against the SHA-256 hash in `models_manifest.json` before it is loaded.

Everything except `streamlit_app.py`, `requirements.txt`, `.streamlit/` and this README (apart from its model table) is
regenerated by the main project's `scripts/15_build_streamlit_app.py`.

Run it locally:

```bash
pip install -r requirements.txt   # Linux wheels; on Windows/macOS install torch and torchvision from pytorch.org first
streamlit run streamlit_app.py
```

## Data and licence notice

The photos come from the **Tomato-Village** dataset: Gehlot, M., Saxena, R.K. & Gandhi, G.C. (2023), "Tomato-Village":
a dataset for end-to-end tomato disease detection in a real-world environment, *Multimedia Systems*,
[doi:10.1007/s00530-023-01158-y](https://doi.org/10.1007/s00530-023-01158-y). The dataset declares no licence.

The 32 photos in `assets/` (8 held-out test photos and 24 library samples) are shown with citation for academic
demonstration only. Please do not reuse them. The full dataset is available from its authors.

This is an experimental classifier trained on photos of detached leaves on white paper. It is not a substitute for
diagnosis by an agricultural expert.
