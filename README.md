# Tomato Leaf Disease Detection: online demo

A Streamlit demo of a BTech Machine Learning Lab project. It classifies photos of tomato leaves (Early Blight, Healthy,
Late Blight, Leaf Miner, Magnesium / Nitrogen / Potassium Deficiency, Spotted Wilt Virus). The project compares
classical machine learning on handcrafted features with deep learning under a **leakage-free** evaluation.

- **Default model:** a focused 5-class ensemble (ConvNeXt-Tiny + EfficientNet-B0) for Healthy, Leaf Miner, Magnesium
  Deficiency, Nitrogen Deficiency and Spotted Wilt Virus.
  - The 5 classes were chosen using validation data only.
  - It gives a diagnosis only when its calibrated confidence is at least 77%, a threshold fixed on validation data.
  - On held-out test photos it scores 90.9% overall and 96.0% on the photos it answers (about 85% of them).
  - It cannot recognise the three conditions it was not trained on. A photo of one of them usually receives a wrong
    label, because the confidence threshold does not catch unknown conditions.
- **The other 9 models** are the 8-class models from the full study: Logistic Regression, SVM, Random Forest, a custom
  CNN, MobileNetV2, EfficientNet-B0 and ConvNeXt-Tiny. You can choose any of them and compare them on the same photo.
- **Grad-CAM** heat maps show where the convolutional models looked.

## How it works

`streamlit_app.py` imports the project's own prediction code, copied unchanged from the main project:

- `backend/services/predictor.py` and `src/tomatoleaf/` handle preprocessing, test-time augmentation, temperature
  calibration, the decision threshold and Grad-CAM.
- On first use, the trained weights are downloaded from this repository's `models-v1` release.
- Each weight file is checked against the SHA-256 hash in `models_manifest.json` before it is loaded.

Everything except `streamlit_app.py`, `requirements.txt`, `.streamlit/` and this README is regenerated by the main
project's `scripts/15_build_streamlit_app.py`.

Run it locally:

```bash
pip install -r requirements.txt   # Linux wheels; on Windows/macOS install torch and torchvision from pytorch.org first
streamlit run streamlit_app.py
```

## Data and licence notice

The photos come from the **Tomato-Village** dataset: Gehlot, M., Saxena, R.K. & Gandhi, G.C. (2023), "Tomato-Village":
a dataset for end-to-end tomato disease detection in a real-world environment, *Multimedia Systems*,
[doi:10.1007/s00530-023-01158-y](https://doi.org/10.1007/s00530-023-01158-y). The dataset declares no licence.

The 32 photos in `assets/` (8 held-out test photos and 24 library samples) are shown with citation for academic
demonstration only. Please do not reuse them. The full dataset is available from its authors.

This is an experimental classifier trained on photos of detached leaves on white paper. It is not a substitute for
diagnosis by an agricultural expert.
